# Imobiliária e operação como fronteiras distintas

A imobiliária é a fronteira de isolamento do cliente, enquanto a operação é a fronteira de números, capacidade, campanhas, agenda e regras de atendimento. Mesmo começando com uma operação, manter os conceitos separados evita que o futuro suporte a múltiplas operações exija partir contatos, permissões e históricos já consolidados.
